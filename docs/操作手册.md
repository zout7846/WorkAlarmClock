## 1. 产品简介

### 1.1 它能做什么

- **自动计时**：按设置里的上班、午休、下班时间与工作日，自动在「工作中 / 午休中 / 休息中 / 已下班」之间切换，并累计每日工时。
- **下班提醒**：下班前先提醒写工作日报，临近下班再用全屏提醒确认打卡；提醒可以设为必须确认。
- **桌宠陪伴**：桌面常驻一只可拖动、可缩放、可换发色或换成自己图片的桌宠；空闲时收起为「灵动岛」胶囊。
- **工作日记**：记录今日事项（可打标签），一键生成 txt / md 工作日报，支持历史日报、周报、统计图表和 CSV 导出。
- **屏幕与工具**：区域截图（支持直接截某个窗口并标注）、番茄钟、倒计时、剪贴板历史、天气、网络状态与测速。

### 1.2 适用环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10（建议 21H2 及以上）或 Windows 11，64 位 |
| 运行时 | v3.0.0 安装包和便携包均自带 .NET 10 Desktop Runtime，无需另装 |
| 屏幕 | 单屏、多屏均可，支持高 DPI 缩放 |
| 网络 | 仅天气、IP 定位、网络测速需要联网；计时、日报、截图等功能离线可用 |
| 权限 | 普通用户权限即可；「开机自启动」只写入当前用户注册表，不需要管理员权限 |

### 1.3 快速开始（约 3 分钟）

1. 启动程序：桌宠出现在屏幕上，同时任务栏通知区域出现图标。
2. 右键桌宠 →「设置」，在「作息」页确认上班时间、下班时间和工作日。
3. 展开桌宠（或双击桌宠打开主面板），点击「开始工作」。
4. 工作过程中在主面板底部输入框记录事项；下班前收到提醒后生成日报。

## 2. 安装与升级

### 2.1 选择版本

从 [GitHub Releases](https://github.com/zout7846/WorkAlarmClock/releases/latest) 下载最新版本。

| 版本 | 文件 | 运行时 |
| --- | --- | --- |
| 安装版 | `WorkAlarmClock-3.0.0-Setup-x64.exe` | 自带 .NET 10 桌面运行时 |
| 便携版 | `WorkAlarmClock-3.0.0-Portable-win-x64.zip` | 自带 .NET 10 桌面运行时 |

便携版请解压整个目录后运行 `WorkAlarmClock.exe`，不要只复制 exe。旧版 `dist`、`pubilc` 与 `publish` 目录不再作为下载入口。

### 2.2 安装步骤（安装包版）

1. 双击 `WorkAlarmClock-3.0.0-Setup-x64.exe`，按安装向导点击「下一步」。
2. 选择安装目录（默认在系统 Program Files 下，可自行修改）。
3. 按需勾选「创建桌面图标」；不需要可直接继续。
4. 点击「安装」，等待完成后可勾选立即启动，再点「完成」。
5. 首次启动后，桌宠出现在屏幕上，通知区域出现图标，数据目录自动创建。

### 2.3 免安装版

- 单文件版：把 `WorkAlarmClock.exe` 放到任意可写目录，双击即可运行。
- 文件夹版：复制整个 `dist` 目录到目标电脑，双击其中的 `WorkAlarmClock.exe`。若提示缺少 .NET，请先安装 .NET 10 Desktop Runtime。

### 2.4 首次启动

- 自动创建 `%LOCALAPPDATA%\WorkAlarmClock\` 数据目录、SQLite 数据库和按月日志。
- 使用默认设置：上班 09:00、下班 18:00、午休 12:00–13:00、工作日周一至周五。
- 首次启动会按默认作息把当天状态落到时间线上；如果启动时正处在午休时段，会自动补记午休。

### 2.5 升级

1. 右键任务栏托盘图标 →「退出」，确认桌宠和主面板都已关闭。
2. 运行新版本安装包覆盖安装，或用新的 exe / 目录替换旧文件。
3. 重新启动。数据库会自动补齐新增字段，历史数据、设置、桌宠位置都会保留。
4. 升级不会删除 `%LOCALAPPDATA%\WorkAlarmClock\` 下的数据；如需回滚，请先按第 9 章备份数据库。

> 说明：同一时间只允许运行一个实例。重复启动会弹出「WorkAlarmClock 已经在运行了，请查看桌面右下角托盘。」，点击确定后新实例自动退出。

### 2.6 卸载

1. 托盘右键 →「退出」。
2. 「设置 → 应用 → 已安装的应用」中找到打卡桌宠并卸载；或运行安装目录下的卸载程序。
3. 卸载不会删除个人数据。如确认不再使用，请手动删除 `%LOCALAPPDATA%\WorkAlarmClock\`（见第 9 章）。

## 3. 界面总览

### 3.1 完整桌宠（展开态，默认 220×420）

| 区域 | 显示内容 | 说明 |
| --- | --- | --- |
| 时钟卡 | 大号 `HH:mm` 时钟、「已工作 HH:mm」 | 显示当前时间与今日累计工作 |
| 状态文字 | 工作中 / 午休中 / 锁屏休息 / 空闲休息 / 休息中 / 已下班 / 待上班 | 颜色随状态变化 |
| 番茄钟胶囊 | 「专注 24:12」 | 仅在番茄钟运行时出现 |
| 气泡 | 提醒文字与按钮（如「立即生成」「稍后提醒」「忽略」） | 普通气泡短暂停留后自动消失；带按钮的气泡需点击按钮 |
| 桌宠立绘 | 内置图片或自定义图片 | 单击有互动动画与台词，同时增加亲密度 |
| 等级徽章 | `Lv.n` 与称号 | 亲密度升级后自动变化，共 5 级 |

桌宠展开态可以按住拖动。释放时如果距离当前屏幕任意一边小于 48 像素，会自动收起成灵动岛；拖到屏幕中间则只保存位置，不收起。

### 3.2 灵动岛（收起态）

收起后桌宠变成黑色胶囊，固定在当前屏幕顶部居中，显示顺序为：状态光晕与状态文字、时间 `HH:mm`、当前活动程序。

![灵动岛收起态](images/legacy/v2.9-compact.png)

- 高度约 38 像素（会随桌宠大小缩放），收起态宽度按内容在 176–400 像素之间自适应，悬停或通知时最多加宽到 520 像素。
- 状态文字带一圈脉冲光晕：工作中为绿色，午休为橙色，其它休息状态为金色，已下班为灰色。
- 单击胶囊会展开回完整桌宠；右键菜单中的「展开桌宠」也可以展开。

### 3.3 悬停展开与通知弹出

鼠标停在灵动岛上约 0.2 秒，胶囊会自动加宽，追加显示「已工作」「今日 N 条」和番茄钟倒计时；移开后恢复紧凑宽度。

![悬停展开](images/legacy/v2.9-hover.png)

通知弹出时胶囊会临时加宽到最多 520 像素显示提醒内容，约 5.5 秒后收回。

![通知弹出](images/legacy/v2.9-notice.png)

### 3.4 主面板（440×790，可缩放至最小 400×560）

双击桌宠，或使用托盘「打开主面板」即可打开。主面板从上到下依次为：

- **顶部信息**：状态胶囊、状态文字（提前结束当天时显示「已结束当天」）、`HH:mm:ss` 大时钟、今日累计工作；右上角四个图标：历史日报、区域截图（提示「区域截图（Ctrl+Alt+A）」）、工作统计、设置。
- **四张统计卡**：工作、休息、午休、本周。
- **操作行**：「开始工作」「开始休息」「结束当天」。
- **番茄钟卡**：倒计时、当前阶段与「今日 N 轮」，以及「跳过」「开始专注 / 停止专注」。
- **工具磁贴**：天气、倒计时、剪贴板、网络（点击网络磁贴会打开测速窗口）。
- **本周统计**：按工作日累计的本周工作与休息时长。
- **今日事项**：标题、标签筛选、「N 条」；列表为空时提示「今天还没有记录」。
- **输入行**：标签下拉框、输入框（占位文字「记录一下你在做什么，回车添加…」）和「添加」按钮。
- **底部按钮**：「生成工作汇报」「日报预览」「隐藏桌宠」。其中「隐藏桌宠」用于在完整桌宠与灵动岛之间切换，等同于 Ctrl+Alt+S。

关闭主面板只是隐藏到托盘，程序继续运行；要真正退出请用托盘「退出」。

### 3.5 状态与含义

| 状态 | 触发方式 | 颜色 | 说明 |
| --- | --- | --- | --- |
| 待上班 | 未到上班时间，或当天不是工作日 | 石板灰 | 不自动计时 |
| 工作中 | 到达上班时间、手动开始、解锁或空闲恢复正常 | 绿色 | 正常累计工时 |
| 午休中 | 午休时段自动切换，或手动开始休息 | 橙色 | 属于休息，不算工时 |
| 锁屏休息 | 锁屏且开启了「锁屏即休息」 | 金色 | 解锁后按规则自动恢复工作 |
| 空闲休息 | 无操作超过空闲阈值 | 金色 | 回来后自动恢复工作并弹「已恢复工作，点此纠正」 |
| 休息中 | 手动点击「开始休息」 | 金色 | 手动状态优先于自动作息 |
| 已下班 | 到达下班时间，或手动「结束当天」 | 灰色 | 当天自动作息不再切换；可手动开始工作补记 |

## 4. 日常操作

### 4.1 一天的典型流程（默认设置）

| 时间 | 自动行为 |
| --- | --- |
| 09:00 | 达到上班时间，状态变为「工作中」，开始计时 |
| 12:00 | 进入午休，状态变为「午休中」 |
| 13:00 | 午休结束，回到「工作中」 |
| 17:30 | 下班前 30 分钟触发弱提醒，提示写工作日报 |
| 17:55 | 下班前 5 分钟触发强提醒，全屏确认打卡 |
| 18:00 | 到达下班时间，自动切换为「已下班」 |

手动操作会覆盖自动判断：例如 10:00 手动点了「开始休息」，即使没到午休时间也会进入休息状态；再点「开始工作」才回到工作。

### 4.2 开始工作 / 开始休息 / 结束当天

三个操作都可在主面板、托盘菜单、桌宠右键菜单中点击，也可以使用全局热键。

| 操作 | 热键（默认） | 说明 |
| --- | --- | --- |
| 开始工作 | Ctrl+Alt+W | 从「待上班」「休息中」「已下班」进入工作中；如果当天已经结束过，这次开始会记为「加班补记」 |
| 开始休息 | Ctrl+Alt+R | 进入休息状态；「已下班」时点它会提示先开始工作 |
| 结束当天 | Ctrl+Alt+E | 把今天锁定为「已下班」，之后不再按作息自动切换；再次「开始工作」即进入加班补记 |

操作失败时会在桌宠上弹出对应提示：

| 情况 | 提示文字 |
| --- | --- |
| 当前已经工作中 | 当前已经处于工作中。 |
| 当前已经休息中 | 当前已经处于休息中。 |
| 已下班后点开始休息 | 今天已结束，加班请点击「开始工作」。 |
| 已下班后再次结束当天 | 今天已经结束啦。 |
| 试图切换到待上班 | 不能手动切换到「待上班」。 |

注意：「结束当天」只影响计时状态，不会关闭下班提醒。若当天想完全安静，可以在设置中关闭对应提醒，或直接退出程序。

### 4.3 自动切换与手动切换的优先级

1. **手动操作**优先级最高，会覆盖自动判断，直到下一次自动节点或手动操作。
2. **自动作息**：到达上班、午休开始、午休结束、下班时间时切换。
3. **锁屏**：开启「锁屏即休息」后，锁屏时自动进入「锁屏休息」；解锁后如果仍在工作时段，会自动恢复工作。
4. **空闲**：无操作超过阈值（默认 5 分钟）进入「空闲休息」；恢复操作后自动回到工作，并弹出「已恢复工作，点此纠正」，点击可改回休息。

午休期间如果人不在电脑前，锁屏或空闲不会覆盖「午休中」状态；午休结束后再按当时情况判断。

### 4.4 番茄钟

- 默认节奏：专注 25 分钟、短休息 5 分钟、长休息 15 分钟，每 4 轮进入一次长休息，专注结束后自动开始休息。
- 打开方式：主面板番茄钟卡的「开始专注」、托盘「开始/停止专注」、桌宠右键「开始/停止专注」、热键 Ctrl+Alt+F。
- 专注中桌宠会显示「专注 mm:ss」胶囊；点「跳过」会立刻结束当前阶段（专注中跳过直接进入休息，休息中跳过则结束本轮）。
- 点「停止专注」结束整个番茄钟；专注期间久坐、喝水提醒会自动暂停，避免打断。
- 专注开始时提示「专注开始，接下来 N 分钟我们一起加油！」；每轮结束和休息结束都有气泡与提示音。

### 4.5 记录今日事项

1. 在主面板底部选择标签（未分类、开发、会议、文档、沟通、学习、工作、其他）。
2. 在输入框写一句「我在做什么」，按回车或点「添加」。
3. 事项按记录时间从早到晚显示在「今日事项」中，可点右侧删除按钮删除；顶部下拉可按标签筛选，选「全部」恢复。
4. 条目为空时不会添加，会提示「请先输入事项内容。」。

今日事项会按编号写进工作日报的「今日工作」栏，也会出现在周报里（带 `[标签]` 前缀）。

### 4.6 生成工作汇报与日报

「生成工作汇报」「日报预览」以及托盘、右键菜单里的同名项，打开的都是「工作汇报预览」窗口。

> 例外：全局热键 Ctrl+Alt+G 不打开预览，而是直接用当天事项和上次保存的「今日工作 / 明日计划 / 风险与待办」生成日报，同时复制全文到剪贴板并弹出气泡提示。需要先编辑内容时，请用主面板、托盘或右键菜单入口。

| 区域 | 作用 |
| --- | --- |
| 左侧 | 只读的日报纯文本预览，随右侧编辑实时更新 |
| 右侧「保存到」 | 显示今天日报将保存到的完整路径 |
| 「今日工作」 | 可手动编辑；留空则自动汇总主面板记录的事项流水 |
| 「明日计划」「风险与待办」 | 可手动填写；留空在日报中显示「无」 |
| 「生成」「复制」「目录」「关闭」 | 生成并落盘、复制全文、打开保存目录、关闭窗口 |

- 文件名格式：`yyyy.MM.dd工作日报.txt`（可设置只输出 txt、只输出 md，或两者都输出）。
- 同一天重复生成会直接覆盖同名文件，不保留 `.bak` 备份（窗口底部有提示）。
- 日报默认模板包含 5 段：日期、工作日报、今日工作、明日计划、问题风险；页脚可在设置中追加一行。
- 自定义模板支持占位符：`{date}`、`{todayWork}`、`{tomorrowPlan}`、`{risks}`、`{work}`、`{rest}`。
- 默认保存目录：`文档\WorkAlarmClock\Reports`；可在「设置 → 存储」修改。
- 生成成功后桌宠会提示「日报已生成并保存：<文件名>」，并给出「打开目录」按钮。
- 历史日报窗口还能一键「生成本周周报」，文件名格式为 `yyyy.MM.dd周报.txt`（或 `.md`，随输出格式设置），以周一日期命名。

### 4.7 统计与历史日报

**工作统计**（主面板右上角图标或托盘右键「工作统计」）：

- 可切换「近 7 天」「近 14 天」「近 30 天」，默认近 7 天。
- 顶部三个指标：区间总工时、工作日日均、最高的一天（显示形如「11.06 · 3.2h」）。
- 每日工时柱状图用两种颜色区分工作与休息。
- 下方「今天的时间轴」按真实时间顺序画出工作（绿）、午休（橙）、休息（黄）、已下班（灰）色块，鼠标悬停可看具体时段。

**历史日报**（主面板右上角「历史日报」）：

- 左侧按日期列出日报，显示星期与事项数；右侧为只读预览。
- 支持按日期或内容搜索，按钮包括「刷新」「生成本周周报」「复制」「打开文件」「打开目录」「关闭」。

### 4.8 区域截图

1. 按 Ctrl+Alt+A，或点主面板相机图标、托盘「区域截图」、桌宠右键「区域截图」。
2. 屏幕冻结并出现遮罩：拖拽框选区域，或直接把鼠标移到某个窗口上单击，截取整个窗口（悬停时会高亮并显示窗口标题）。
3. 松开鼠标完成选择；按 Esc 或点右键取消。
4. 进入标注窗口，可用矩形、箭头、画笔、文字标注，颜色有红、黄、蓝，可撤销、复制、保存或关闭。
5. 保存后 PNG 写入截图目录，文件名形如 `2026.11.07_143005.png`；桌宠提示「截图已保存：<文件名>」，可点「打开目录」。
6. 若开启「截图后自动复制到剪贴板」，保存时同时复制图片。

截图目录默认是 `图片\WorkAlarmClock\Screenshots`，可在「设置 → 存储」修改；多显示器会整屏抓取，遮罩覆盖所有屏幕。

### 4.9 桌面小工具

| 工具 | 打开方式 | 主要功能 |
| --- | --- | --- |
| 倒计时 | 主面板「倒计时」磁贴 | 预设 5/10/15/25/30/45 分钟，也可自定义 1–600 分钟；开始/停止；到点气泡提示并响铃 |
| 剪贴板历史 | 主面板「剪贴板」磁贴 | 自动记录复制的文本（保留最近 50 条），可搜索、复制、删除、清空 |

| 网络测速 | 点击主面板「网络」磁贴 | 半圆仪表盘实时显示下载、上传、延迟；下载使用国内镜像节点，上传使用 Cloudflare |

天气数据来自 Open-Meteo 免费接口；定位失败或城市无数据时显示「暂无数据」，可在设置里手动填写城市、纬度和经度。

### 4.10 健康提醒

- 久坐提醒：默认每 60 分钟一次；喝水提醒：默认每 90 分钟一次。
- 只在「工作中」计时，离开工作状态后计时清零；番茄钟专注期间暂停。
- 提醒以桌宠气泡出现；久坐提醒带「已起身」按钮，点击后重新计时。

## 9. 数据与隐私

### 9.1 数据保存在哪里

所有个人数据都保存在当前用户目录，不会上传到任何服务器。

| 路径 | 内容 |
| --- | --- |
| `%LOCALAPPDATA%\WorkAlarmClock\workalarm.db` | SQLite 主数据库：设置、每日记录、状态流水、事项、日报记录、提醒状态 |
| `%LOCALAPPDATA%\WorkAlarmClock\workalarm.db-wal`、`workalarm.db-shm` | SQLite 运行时临时文件，属正常现象 |
| `%LOCALAPPDATA%\WorkAlarmClock\logs\app-yyyy-MM.log` | 按月日志，排查问题用 |
| `%LOCALAPPDATA%\WorkAlarmClock\backups\workalarm-yyyy.MM.dd.db` | 每日自动备份 |
| `%LOCALAPPDATA%\WorkAlarmClock\backups\workalarm-yyyy.MM.dd_HHmmss.db` | 手动备份 |
| `%LOCALAPPDATA%\WorkAlarmClock\clipboard-history.json` | 剪贴板历史（开启时） |
| `%LOCALAPPDATA%\WorkAlarmClock\data_legacy_backup\` | 从旧版 JSON 升级时归档的原始数据（含旧 `settings.json`、`data\*.json`），保留不删 |
| `文档\WorkAlarmClock\Reports\` | 生成的日报、周报文件 |
| `文档\WorkAlarmClock\Export\<时间戳>\` | 导出的三个 CSV 文件 |
| `图片\WorkAlarmClock\Screenshots\` | 区域截图 PNG |

说明：v1.1 起设置改存数据库的 `settings` 表。`settings.json` 仅存在于旧版本或 `data_legacy_backup\` 中，用于升级迁移，程序不再读取和写入它。

### 9.2 联网行为

| 功能 | 访问对象 | 发送内容 |
| --- | --- | --- |
| 天气 | Open-Meteo 免费接口 | 城市或经纬度 |
| IP 定位 | ipwho.is / myip.ipip.net / ip-api.com 三源并发竞速，2.5s 上限，境内城市优先 + 一致性校验 + CityPresets 坐标兜底 | 本机公网 IP（由对方服务器识别） |
| 网络测速 | 国内镜像节点与 Cloudflare | 测速请求，不上传文件内容 |

除此之外没有账号、没有云同步、没有埋点统计。摄像头、麦克风、音频检测全部在本机读取系统状态，不采集、不保存、不上传画面和声音。

### 9.3 备份与恢复

1. 托盘右键 →「退出」，确保程序已完全关闭。
2. 打开 `%LOCALAPPDATA%\WorkAlarmClock\`，把 `workalarm.db` 复制到安全位置；也可以先「设置 → 存储 → 立即备份」再复制 `backups` 中的备份文件。
3. 恢复时先退出程序，把备份文件改名为 `workalarm.db` 覆盖回原目录；如存在 `workalarm.db-wal`、`workalarm.db-shm`，一并删除后再启动。
4. 恢复后启动程序，历史记录与设置会回到备份时的状态。

### 9.4 清理

- 退出程序后删除 `%LOCALAPPDATA%\WorkAlarmClock\` 可清空全部数据（不可恢复，请先备份）。
- 日报、截图、导出的 CSV 在「文档」「图片」目录下，需要按需单独删除。

## 10. 后门工具 WorkAlarmClock.Admin

`WorkAlarmClock.Admin` 是一个控制台数据库工具，用于在程序打不开或需要批量维护时查看、修改、备份数据。

### 10.1 启动方式

源码目录下可用 dotnet 运行（需要 .NET SDK 10）：

```powershell
dotnet run --project .\WorkAlarmClock.Admin\WorkAlarmClock.Admin.csproj -- overview
```

也可以直接运行编译产物 `WorkAlarmClock.Admin\bin\Debug\net10.0\WorkAlarmClock.Admin.exe`。不指定命令时进入交互式菜单。

数据库路径优先级：`--db` 参数 > 环境变量 `WORKALARM_DB` > `%LOCALAPPDATA%\WorkAlarmClock\workalarm.db`。

```powershell
# 查看数据库概览
dotnet run --project .\WorkAlarmClock.Admin\WorkAlarmClock.Admin.csproj -- overview

# 查看指定数据库的某一天
dotnet run --project .\WorkAlarmClock.Admin\WorkAlarmClock.Admin.csproj -- --db "D:\备份\workalarm.db" day 2026-11-06

# 最近 7 天汇总
dotnet run --project .\WorkAlarmClock.Admin\WorkAlarmClock.Admin.csproj -- summary 7

# 用环境变量指定数据库
$env:WORKALARM_DB = "D:\备份\workalarm.db"
```

### 10.2 命令一览

| 命令 | 说明 |
| --- | --- |
| `overview` | 显示数据库路径、文件大小、各表行数、日期范围 |
| `day <yyyy-MM-dd>` | 查看某天的记录与状态流水 |
| `summary <N>` | 最近 N 天工时汇总（N 为 1–366） |
| `settings` | 查看当前设置 |
| `settings-set 键=值 [...]` | 修改设置，可一次改多项 |
| `backup` | 立即备份数据库 |
| `delete-day <yyyy-MM-dd>` | 删除某天的全部数据 |
| `clear-tasks <yyyy-MM-dd>` | 清空某天的事项 |
| `export <yyyy-MM-dd\|all>` | 导出状态流水为 CSV |
| `help` | 显示帮助 |
| 不指定命令 | 进入交互式菜单（1 概览 / 2 某天 / 3 最近 N 天 / 4 设置 / 5 数据维护 / 6 导出 / 0 退出） |

### 10.3 可修改的设置项

`settings-set` 支持的键：

| 键 | 含义 | 示例值 |
| --- | --- | --- |
| `WorkStartTime` | 上班时间 | `09:00` |
| `WorkEndTime` | 下班时间 | `18:00` |
| `LunchEnabled` | 是否启用午休 | `true` / `false` |
| `LunchStartTime` | 午休开始 | `12:00` |
| `LunchEndTime` | 午休结束 | `13:00` |
| `Workdays` | 工作日，1–7 表示周一至周日，逗号分隔 | `1,2,3,4,5` |
| `CountIdleAsWork` | 空闲是否计入工时 | `false` |

布尔值可用 `1/true/yes/y/是` 表示真，`0/false/no/n/否` 表示假。未列出的设置项会原样保留。

### 10.4 安全机制与注意事项

- 所有写操作（`settings-set`、`delete-day`、`clear-tasks`）执行前会自动用 `VACUUM INTO` 备份到数据库同级的 `backups` 目录，并要求输入 `y/N` 确认。
- 删除与清空操作会提示「建议先退出 WorkAlarmClock 应用再执行删除/清空。」，请先关闭主程序，避免数据库被占用或覆盖。
- `export` 输出带 UTF-8 BOM 的 CSV，默认保存到数据库目录下的 `exports\transitions-<范围>-<时间戳>.csv`，也可用 `--out <路径>` 指定；列为：id、日期、时间、原状态码、原状态、新状态码、新状态、来源码、来源、备注。
- 工具会直接读写数据库，操作前请确认路径；不确定时先用 `overview` 和 `backup`。

## 11. 常见问题（FAQ）

### Q1：托盘里找不到图标怎么办？

Windows 11 默认会把新图标收进「其他系统托盘图标」折叠区。点击任务栏右下角的「^」，找到打卡桌宠图标；如需常驻，打开「设置 → 个性化 → 任务栏 → 其他系统托盘图标」，把它设为显示。若仍找不到，先退出程序再重新启动。

### Q2：桌宠不见了，但程序还在运行？

按 Ctrl+Alt+H 可以重新显示；也可以在托盘菜单点「显示/隐藏桌宠」。如果之前用右键「隐藏桌宠」隐藏了，同样用这两种方式恢复。程序重启后桌宠会重新显示。

### Q3：状态一直显示「待上班」？

先确认三点：今天是否在「设置 → 作息 → 工作日」勾选；当前时间是否已到上班时间；是否手动「结束当天」后没有再开始。满足条件仍不变时，直接点「开始工作」（Ctrl+Alt+W）即可立即进入工作。

### Q4：午休时间到了，为什么没有自动变成「午休中」？

这个问题已在 v2.9.1 修复：此前若在 12:00 前因空闲或锁屏进入过休息，午休开始会被忽略。请升级到 v2.9.1 或更高版本。升级后，如果程序在午休时段内启动，还会自动补记当天午休。仍不生效时检查「设置 → 作息」中「启用午休」是否打开、午休时段是否正确。

### Q5：灵动岛看不到摄像头 / 麦克风活动？

该提示只在程序真正占用摄像头或麦克风时出现，正常聊天、看视频不会触发；系统隐私设置或驱动不提供使用状态时也可能检测不到。关闭占用程序后约 1.5 秒提示消失，属正常设计。

### Q6：灵动岛的活动文字一闪就没了？

活动文字默认保持约 3 秒，之后自动隐藏；如果随后出现更高优先级活动（摄像头 > 麦克风 > 音频 > 截图），会立即替换。这是为了避免长期占用屏幕，不是故障。

### Q7：截图比例或位置不对怎么办？

截图会整屏抓取虚拟桌面，多显示器时遮罩覆盖所有屏幕。若跨不同缩放比例的显示器框选，可能出现位置偏差：请把选区限制在单个屏幕内，或把系统缩放统一。建议使用 v2.9.1 及以上版本；如仍有问题，请附上日志 `%LOCALAPPDATA%\WorkAlarmClock\logs\`。

### Q8：按下截图热键没反应？

先确认程序正在运行；再检查是否被其它截图软件占用了 Ctrl+Alt+A。可以在「设置 → 热键 → 区域截图」重新录制一组组合键，保存后立即生效。

### Q9：下班提醒没有弹出？

检查「设置 → 提醒」中弱提醒、强提醒是否开启，提示音是否关闭；当天是否为工作日；强提醒是否已经被确认或忽略。若之前手动「结束当天」，提醒仍会按时间触发，可关闭对应开关让当天安静。

### Q10：日报保存在哪？为什么找不到 .bak？

默认在 `文档\WorkAlarmClock\Reports`，文件名形如 `2026.11.07工作日报.txt`；可在「设置 → 存储」修改目录，或在历史日报窗口点「打开目录」。同一天重复生成会直接覆盖，不再生成 `.bak` 备份，请用自动备份或手动备份保留历史。

### Q11：怎么备份数据、换电脑怎么迁移？

最简单的方式：退出程序后复制整个 `%LOCALAPPDATA%\WorkAlarmClock\` 目录到新电脑同一位置；或复制 `workalarm.db` 文件。也可以使用「设置 → 存储 → 立即备份」或 Admin 工具 `backup` 命令。恢复前请先退出程序。

### Q12：启动时提示「WorkAlarmClock 已经在运行了」？

程序只允许运行一个实例，说明托盘里已有实例。点击托盘图标打开主面板即可；如果确实找不到窗口，检查通知区域折叠菜单，或在任务管理器中结束 `WorkAlarmClock` 进程后重新启动（结束后请等待几秒再启动）。

### Q13：卸载后数据还在吗？

在。卸载程序只删除安装目录，不删除 `%LOCALAPPDATA%\WorkAlarmClock\`。如需彻底清理，请退出程序后手动删除该目录；删除前建议先备份数据库。

### Q14：番茄钟运行期间久坐、喝水提醒为什么不弹？

这是设计行为：专注期间会暂停健康提醒，避免打断；专注结束进入休息后恢复计时。如果不需要番茄钟，点「停止专注」即可。

### Q15：如何更换桌宠图片或发色？

打开「设置 → 外观」：发色可选蓝发、粉发、绿发、暖棕；「选择图片…」支持 PNG/JPG/GIF，透明背景 PNG 效果最佳。修改后点「保存」，部分项目保存后立即生效；「恢复默认」可还原内置图片。
