## P0（Must have）

### R-01 悬浮桌宠窗口 ✅
- 置顶（Topmost）、无边框（WindowStyle=None）、透明背景（AllowsTransparency）。
- 手工拖动（未用 DragMove，DPI 换算正确）；释放后距工作区左/右/上边缘 ≤30px 自动吸附并收缩为 8px 窄条（Opacity 0.35），MouseEnter 展开。
- 双击（带位移阈值判定，避免拖动误触）打开主面板。
- **验证**：真机拖动贴边 → 收缩窄条；settings.json 记忆 `PetCollapsed:true`；重启后恢复收缩态与位置（T01–T03 冒烟实测通过）。

### R-02 实时时钟与状态显示 ✅
- 气泡显示 HH:mm 时间（秒级 Tick 刷新）、已工作时长 HH:mm（每秒重算流水派生）、状态文案（待上班/工作中/休息中/午休中/锁屏休息/空闲休息/已下班）。
- **验证**：六场景启动落位日志的状态文案全部正确；Tick 每秒驱动。

### R-03 桌宠表情与动作 ✅
- 纯 XAML 矢量卡通角色（Ellipse/Path/Canvas），**5 组表情**：工作（敲键盘）、休息（闭眼 zZ）、午休（咀嚼+饭碗热气）、弱提醒（举"日报"牌）、强提醒（跳起+红叹号闪烁）+ 各自待机 Storyboard；DataTrigger 按状态+提醒叠加切换。
- **验证**：编译运行无异常，动画 Begin(controllable) 不阻塞 UI 线程。

### R-04 作息时间表配置 ✅
- 上班/下班/午休起止、工作日七勾选、午休开关；默认 09:00–18:00、午休 12:00–13:00、周一至周五。
- **验证**：settings.json 持久化 + 重启加载；非法配置（如午休早于上班）被校验拦截并回退默认（实测：构造非法测试配置 → 日志 WARN「设置文件校验失败，已回退默认设置」+ 文件被自动纠正）；非工作日不自动计时、不提醒（六场景之非工作日验证）。

### R-05 自动状态机 ✅
- 到点自动切换 4 个时间点（上班/午休/午休结束/下班）；跨时间点启动正确落位；手动结束后当天不再自动切回。
- **验证**：六种启动场景（上班前 08:00→待上班 / 上午 10:30→工作中 / 午休中 12:30→午休中 / 下午 15:00→工作中 / 下班后 19:00→已下班 / 非工作日周日→待上班）经 WORKALARM_TEST_NOW 时钟注入逐场景真机运行，日志状态全部正确；Tick 每秒对账，睡眠唤醒/时钟跳变后 1 秒内自愈。

### R-06 锁屏检测 ✅

- **验证**：代码路径 + 事件接线审查通过；锁屏人工场景未在本轮自动化执行（需要真实锁屏操作），逻辑与解锁恢复路径已实现。

### R-07 空闲检测与恢复策略 ✅

## 已知限制与后续建议

1. **锁屏/解锁（R-06）**：代码路径完整，但本轮自动化测试未执行真实锁屏操作，建议日常使用中观察一次。
2. **设置面板/预览面板的纯 UI 交互**（红字提示、滑条即时生效、按钮点击）：命令与绑定已接通，建议人工过一遍。
3. **测试钩子**：`WORKALARM_TEST_NOW` 环境变量可注入时钟（按真实速率前进）用于场景模拟，正常启动不受影响；生产使用不需要设置。
4. **手动休息恢复语义**（架构 D-08 规则 3）：当前"手动休息不抑制作息点与回岗恢复"，如需"手动休息必须手动恢复"只需改 `TryManualSwitch` 一处来源判断。
5. **时间回拨跨日极端场景**：回拨跨过午夜会触发提醒状态重置（当日标志清零），极端边界下可能重复提醒一次，个人工具可接受。

### R-87 修复「午休已启用但不自动执行」✅
- 现象：把午休设为 12:00–13:00 并启用后，12:00 不会切到「午休中」，午休时长始终为 0，导出表里的午休分钟也是 0。

- 修复：`target == current` 且为午休开始时，改为追加一条 `Resting→Resting`、`Source=Schedule`、备注「午休开始」的流水 → `Recompute` + `Persist` + `StateChanged`。时长与来源始终由流水派生，落流水才不会被重放覆盖。

### R-89 托盘图标健壮性加固 ✅

### R-91 修复「区域截图 / 自定义 ROI」比例失真 ✅
- 现象：截图标注窗里预览被拉扁/拉长，箭头与文字也跟着变形；自定义 ROI 越极端（宽扁或窄高）越明显。
