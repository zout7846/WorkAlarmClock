# 版本记录

## v3.0.0 · 2026-11-10

- 浅蓝网页工作台布局，左侧主导航；工具保留独立窗口并提供顶部导航。
- 统一按钮、输入框、卡片和设置页，修复进制键盘、倒计时以及小窗口布局裁切。
- 热键注册失败和运行时操作异常改为页面消息轮播，支持消息记录。
- 天气支持手动选择城市、逐小时降水柱形/曲线预报；测速提供实时速率曲线；统计提供工时趋势和占比环图。
- 新增四则计算器、二/八/十/十六进制互转工具。
- 二维码和常见条码生成、图片识别、粘贴、复制及导出；支持 px/mm/cm 尺寸，配置保存到 SQLite。
- 变量名生成支持中英互译、五种中文标注的命名格式、复制粘贴和全局热键；翻译服务失败时自动尝试备用服务。
- 图片转换支持 PNG/JPG 互转、批量 ICO 尺寸导出、单文件多帧 ICO，以及原图、尺寸和路径预览。
- 截图支持马赛克；窗口缩放时保持原图及标注坐标。
- 安装包和便携包均包含 .NET 10 Windows 桌面运行时；修复旧安装脚本遗漏依赖的问题。

发布前验证：工具/设置窗口的正常与最小尺寸 WPF 渲染、6 个设置分区、主工作台页面、进制按键、消息历史及热键失败路径、上传仪表数据、图表数据一致性、截图缩放回归。桌面鼠标点击与真实网络测速不属于这组自动验证。
