## 2026-11-07 v2.9.1：午休不自动执行 / 托盘图标 / 测试时钟

### 午休 Bug（R-87）
- 现象：午休启用（12:00-13:00）但 12:00 不切「午休中」，午休时长恒 0。
- 根因：12:00 前已被空闲检测带入 Resting，`ApplySchedulePoint(LunchStart)` 命中 `target == current` 分支只改内存 `_currentRestSource`，没有落流水；`Recompute` 用 ReplayCalculator 重放流水又算回 Idle。**时长/来源完全由流水派生，任何来源变化都必须落流水**。
- 修复：改为追加 `Resting→Resting`、`Source=Schedule`、Note="午休开始" 的流水；另加 `EnsureLunchOnLoad`：启动时已在午休时段内则补一条时间戳为当天 12:00 的午休流水（或从 Working 切 Resting），因为 `_lastAppliedPoint` 会被直接置成 12:00，错过点不会再触发。

### 测试时钟（R-88）
- `AppServices.ConfigureServices` 之前没接收 `testClock`，`ClockTicker` 永远用真实时钟；改为 `services.AddSingleton(sp => new ClockTicker(testClock))` 后 WORKALARM_TEST_NOW 才真正生效。

### 托盘图标（R-89）
- Win11 XAML 托盘无法用 UIA 枚举（Shell_TrayWnd 只有 5 个后代，没有溢出窗口）；只能靠代码保证 NotifyIcon 真的带 Icon。
- `InitializeTray` 改为：先加载图标（失败回退 `SystemIcons.Application.Clone()`）→ `new NotifyIcon { Icon, Visible=false }` → 菜单/事件 → `UpdateIcon` → `Visible=true`；日志打印 `Icon=ok/null`。

### 踩坑
- 用 PowerShell 5.1 执行含中文的 .ps1 时，UTF-8 无 BOM 会被当 ANSI 解释，某些汉字的尾字节会“吃掉”换行，导致下一行被并进注释（本次让 `WORKALARM_TEST_NOW` 赋值变成注释，排查了很久）。**测试脚本一律纯 ASCII，中文数据用 python 写 UTF-8 文件或数据库**。
- 截图脚本要隐藏其它 WorkAlarmClock 实例窗口（用户可能在 VS 里同时跑一份），否则截图出现重影胶囊。
